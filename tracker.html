Pattern 01: Dict lookup
The four steps for every pattern
  1. Read the lesson. Open a_lesson.md in the pattern's folder and type in the worked example.
  2. All tests pass. Solve problems 2 and 3 in c_practice.py until the command shows every test passing.
  3. Rewrite from memory the next day. Run python practice.py N --reset to blank your answers, then write them again without looking.
  4. Rewrite again a week later. If you can still do it, you own the pattern.

Watch a pattern's video before its lesson. Each problem has its own video in the pattern's b_videos.md: have a real go for 20 to 30 minutes first, then watch it. New to practising like this? Start with How I would learn Leetcode if I could start over (NeetCode).
