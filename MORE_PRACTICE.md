# More practice

Every pattern has 5 to 7 extra problems on LeetCode. They're free, and you can run and test your code in LeetCode's own editor.

**How to use them:** once all 3 problems in a pattern pass, do at least 3 of these before ticking "All tests pass" on the tracker. Start with the Easy ones. Give each one 20–30 minutes before looking at a video or the solution.

NeetCode (https://neetcode.io/practice) groups problems by topic too, each with a free video. The topic to look under is listed for each pattern.
